## 0. 先说这个来源的硬限制

**小红书的价格几乎全在图片里，正文只有一两句话加话题标签。**

实读两篇验证：
- 「Costco黑五折扣目录(11/17-12/1)」（2025-11-24，491赞）正文全文 = "需要Costco会员卡或礼品卡才能购买 / Macbook Air/平板/耳机/戴森吸尘器/吹风机各种好价" + 标签。价格在 7 张图里。
- 「澳洲黑五必买清单！留学生省钱攻略」（10-22，375赞）正文全文 = "大概就列啦这些"。价格在 3 张图里。

后果：PRD §5.1 要的 `evidence`（"原网页上含价格的原句"）在这类笔记里**不存在**。
标题里带价格的那一类是例外（见 §5），那种可以直接引用标题。

### ⚠️ 第二个坑：搜索结果会混进非澳洲内容

搜「2026黑五购物日历 品牌折扣时间表」，排第一的那条点开是**🇰🇷韩国黑五时间表**，正文里也写着
"2026 黑五购物日历｜品牌折扣时间表"，不看正文根本分不出来。
「Costco黑五折扣目录」那条的评论区更明显，大半是美国、加拿大用户在问"比加拿大的贵啊"
"看了价格好激动 结果发现是澳洲"。

**任何从小红书取来的信号都必须先过一道澳洲过滤**，否则会把韩国/美国/加拿大的档期和价格
当成澳洲的写进去。标题带 🇦🇺 的相对可靠，但不能只靠这个。

**所以小红书的定位是选品 + 时间表 + 技巧，不是价格点来源。**
同样的内容，Dealmoon 的网站 `www.dealmoon.com.au` 是服务端渲染的**文字**页面 —— 要价格点该去那里。
（注：袋鼠dealmoon 在多个搜索里都出现，是同一家的小红书号。）

## 12. 第四轮：电脑 / 避坑 / Outlet

### 🔑 苹果：解释了为什么 `macbook-air` 在 OzBargain 抓到 0 行

这是本次盘点里最有解释力的一条发现。

`macbook-air` 是 `watch.json` 的关注品，但 OzBargain 黑五 2533 行里**一条都没有**。
小红书给出了原因：**苹果在澳洲黑五不降价，它返礼品卡。**

| 证据 | 赞 |
|---|---|
| 「Apple黑五终于来了🥹共4天！！🛍️**买就得gf**（gift card）」 | 281 |
| 「悉尼黑五苹果大扫购**喜提400刀礼品卡**」 | 23 |
| 「🇦🇺**Costco黑五Airpods/Mac打折啦**！!」 | **534** |
| 「贡献个澳洲黑五，apple店买Macbook实战」 | 48 |
| 「黑五**jbhifi 礼品卡23张**刷笔记本电脑」 | 4 |
| 「🇦🇺黑五macbook怎么买？求助」/「留学生想黑五买台macbook 选air还是pro」 | 97 / 78 |

**含义很重要**：`macbook-air` 抓不到，不是因为没人买，而是**折扣的形态（返卡 / 礼品卡叠加）
不是降价，价格型管道天然看不见**。页面如果照搬 OzBargain 的数据，会得出"MacBook 黑五没好价"
这个错误结论。苹果这类商品必须单独按"返卡价值"处理，或者在页面上标明口径不同。

那条「礼品卡23张刷笔记本电脑」是极端案例，但方向是对的：华人买苹果走的是
**折扣礼品卡 → 叠加 → 返卡** 这条链，和 §2 的礼品卡层是同一件事。

另：「老板疯了？澳洲黑五折扣**延长到12月10日**」—— 黑五档期会被商家自行延长，
`event` 的 11/10–12/02 窗口会漏掉这种尾巴。

### Boxing Day 的日期层：州与州不一样

搜「澳洲boxing day时间几点」出来的大半不是折扣，是**公共假期和营业时间**：

  「Chemist Warehouse圣诞开门时间」

**这对 `calendar.json` 是个真问题**：Boxing Day 在澳洲各州的公共假期和营业规则不同
（南澳、西澳的零售营业限制和东部各州不一样），所以"Boxing Day 什么时候开卖"**没有全国统一答案**，
线下和线上也不同步（线上常常 12/24 就开）。`calendar.json` 如果只写一个全国日期，会是错的。
